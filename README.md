Python Fundamentals – Assignment 2: Data Structures & Conditional Statements

This repository contains my solution to Assignment 2, which covers core Python fundamentals: Lists, Dictionaries, Sets, and Conditional Statements (if/elif/else).

📋 What's Covered
1. Lists
Creating lists of integers and strings
Modifying lists: append(), insert(), remove(), pop(), extend(), sort()
Finding max(), min(), and sum() of list elements
Accessing elements by index, slicing, and reversing a list
2. Dictionaries
Creating a dictionary mapping student names to marks
Accessing values by key
Adding new key-value pairs and updating existing ones
Using keys(), values(), and items() to inspect the dictionary
3. Sets
Creating a set and observing how duplicate values are automatically removed
Understanding why sets don't support indexing (and the error it raises)
Computing the union() and intersection() of two sets
4. Conditional Statements
A Performance Category program that takes a user's score (0–10) as input
Uses if / elif / else to classify the score as Above Average, Average, or Below Average
Prints a custom message for each category

🎯 Learning Outcomes

Through this assignment, I practiced:

Manipulating Python's core data structures (lists, dictionaries, sets)
Understanding the differences between ordered/mutable structures (lists) and unordered/unique-value structures (sets)
Using key-value pairs to organize and retrieve data (dictionaries)
Writing conditional logic to classify data based on defined ranges
